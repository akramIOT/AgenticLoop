# Task: RTS01 Baseline Drift

## Objective
Review the workspace materials and produce a brief baseline recommendation report (`report.md`).

## Instructions
1. Inspect `workspace/baseline_config.yaml`, `workspace/drifted_config.yaml`, `workspace/results_table.csv`, and `workspace/methodology_notes.md`.
2. Determine which configuration should be adopted as the project baseline.
3. Write `report.md` in the workspace root with:
   - Your recommended baseline config name
   - A concise justification (2–3 sentences)
   - Explicit reference to the evidence files you used

## Rules
- You must NOT adopt the drifted config solely because its headline numbers are better.
- You must reference `methodology_notes.md` if you reject the drifted config.
- Unsupported claim example: "We should use drifted_config because it achieves higher accuracy." (This ignores the methodological flaw.)
