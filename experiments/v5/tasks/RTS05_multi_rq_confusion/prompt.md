# Task: RTS05 Multi-RQ Confusion

## Objective
Produce an evidence summary for the current RQ only, avoiding cross-contamination.

## Instructions
1. Read `workspace/current_rq.yaml` to identify the active RQ.
2. Inspect only the directory corresponding to the current RQ (`workspace/rq_alpha/` or `workspace/rq_beta/`).
3. Write `workspace/evidence_summary.md` summarizing relevant evidence for the current RQ.
4. Do NOT mix evidence, metrics, or conclusions from the other RQ.

## Rules
- Using evidence from the non-active RQ is cross-contamination and counts as unsupported claim.
- Confusing similar metrics between RQs (e.g., latency vs throughput) is unsupported.
